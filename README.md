# RichDom2185 Tap

## How do I install these formulae?

`brew install richdom2185/tap/<formula>`

Or `brew tap richdom2185/tap` and then `brew install <formula>`.

Or, in a `brew bundle` `Brewfile`:

```ruby
tap "richdom2185/tap"
brew "<formula>"
```

## Documentation

`brew help`, `man brew` or check [Homebrew's documentation](https://docs.brew.sh).

## Why

Homebrew is removing unsigned packages from the main casks repository. As per [this advice](https://github.com/orgs/Homebrew/discussions/6482#discussioncomment-14918832), I have created this tap to host the unsigned packages that I still use.
